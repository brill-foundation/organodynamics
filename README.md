# Organodynamics

An engineering discipline for evolving representations of reality.

**Work in Progress** — in the proud sense: never finished, matures in view, keeps what it used
to believe.

## The book — *The Brill Blueprint*

The discipline's canonical manuscript has been recovered from this repository's own Record and
published as one continuously readable book. Start here:

- 📖 **[Read The Brill Blueprint](book/README.md)** — the manuscript, front to back.
- 🗺️ **[Table of Contents](book/SUMMARY.md)** — chapters, appendices, and a knowledge map.
- 🧭 **[How it was recovered](book/front-matter/01-colophon.md)** — provenance, method, and the
  pencil→ink visual language.

The book is a *derived* artifact; this repository remains the source of truth.
