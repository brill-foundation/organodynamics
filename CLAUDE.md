# Arrival

You are sitting down at your desk. However much you already carry from before,
orient yourself here first.

This repository is the sovereign source of truth — the memory that every
participant can rely on, regardless of how much they personally remember. Some
arrive with a Home already prepared; some reconstruct it on arrival. Either way,
the repository is where you find where you stand. So before looking through the
Window — before any work — establish your standpoint.

## Orient before acting

1. Read the living point of orientation: **`ORIENTATION.md`** — the desk you are
   sitting down at (the current standpoint, the active branch, where work lives).
   Read it first and follow where it points.
2. Synchronize with the repository as it is now (`git status`, `git log`) — not as
   any conversation remembers it.
3. The repository has priority over conversation memory, always. Where they
   disagree, the repository is right.
4. If the standpoint is unclear, ask before acting. Uncertainty is resolved by
   looking or asking — never by assuming.

## The workshops

Numbered conversations — `Organodynamics 001, 002, … NNN` — are archived thinking
workshops. They are **not** versions, branches, or parallel realities; never
canonical; never merged with one another. Only the unnumbered **Organodynamics**
is active. When a workshop ends it is archived with the next number and a new one
begins. A workshop is a temporary place for thinking; what deserves to survive is
distilled into the repository.

The repository is what persists. Workshops come and go. Participants come and go.
Implementations come and go. The repository is what remains.
