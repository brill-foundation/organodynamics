# Illustration plate slots

This directory holds the **atlas-grade illustration plates** — the richer renderings specified
in the [Illustration Plan](../../editorial/05-illustration-plan.md) but not yet produced. They
add craft to *fixed meaning*: each has a canonical source and a fixed frame, so a future
illustrator adds polish, not doctrine.

Every meaning these plates will carry is *already conveyed* by a ship-now figure embedded in the
chapters (Mermaid / text construction blocks). Producing the plates closes
[Gap G-8](../../editorial/07-outstanding-gaps.md).

| File to produce | Figure | Source | Frame |
|-----------------|--------|--------|-------|
| `fig-4.1-atlas.*` | Reality Layers — atlas spread | RFC-001 §6, §7 | The stack + loop + Observatory on one spread, pencil→ink gradient across the page |
| `fig-7.1-plate.*` | The Sun — frontispiece plate | RFC-001 §7 | The pencil sketch (FIG-7.1) matured toward ink as Chapter 7 progresses |
| `fig-0.1-mark.*` | The Door — book mark / logo | RFC-001 §5.4 | A door glyph as the book's recurring mark (candidate for `assets/logos/`) |

Conventions: preserve the maturity semantics of the [Visual Language
Guide](../../editorial/06-visual-language-guide.md) — the pencil→ink gradient is *content*, not
decoration. Prefer SVG (diffable, scalable) over raster where possible.
