# Design Space

*A provisional home. This folder's name is a placeholder.*

Names become architecture surprisingly quickly here, so this space does not
claim its own vocabulary yet. It temporarily holds a family of objects whose
permanent home the repository has not yet earned the right to name. When the
architecture settles enough to reveal what this family should be called, this
folder will be renamed — and git will remember it was once here. The important
thing is not the folder name; it is the **role**.

## What this space is for

Living **design references**: objects that look *forward*, that future design
work returns to continuously. They are deliberately neither of the two things
they might be mistaken for:

- Not **Cabinet artifacts** — the Cabinet looks backward, preserving what
  happened, interpreted by no one.
- Not **Record entries** — the Record preserves only what reality has already
  taught. Nothing here has earned that standing.

A reference held here guides exploration. It does not prove anything.

## The discipline of this phase

> I don't want to preserve the conclusion before we preserve the experience.

This sentence governs the current work. Reality is still teaching us. The
repository preserves the things that help us keep learning; the Record
preserves only what reality has already settled. Until reality keeps pointing
at the same recognition — without our forcing it — the architecture these
references suggest remains a **working hypothesis**, not knowledge, and it
stays out of the constitutional Record.
