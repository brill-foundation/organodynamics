# Peace Table foundation

This directory holds the versioned product foundation for Garnet's Peace Table direction.

## Current documents

- [`garnet-first-table-v0.1-he.txt`](garnet-first-table-v0.1-he.txt) — faithful plain-text extraction of the operator-provided DOCX handoff. It is preserved as source material and is not the current specification.
- [`garnet-first-table-v0.2-he.md`](garnet-first-table-v0.2-he.md) — immutable historical foundation version, superseded by v0.3. Preserved as source material; do not silently edit it.
- [`garnet-first-table-v0.3-he.md`](garnet-first-table-v0.3-he.md) — **current working foundation**. Identical to v0.2 except version/provenance metadata and a narrow §9.1 constitutional amendment: a ratified, versioned, scoped, expiring, revocable human Mandate can satisfy §9's "explicit human approval" for eligible reversible Tier-2 actions inside the Mandate's exact scope and lifetime, through the dual-independent-model, bounded-reconciliation, dual-attestation controls; Tier 3 remains permanently non-delegable; this amendment alone does not activate any live Tier-2 execution.
- [`../peace-table-architecture-v0-he.md`](../peace-table-architecture-v0-he.md) — proposed architecture and staged build plan derived from the foundation. It is an implementation proposal, not part of the constitution.
- [`../peace-table-decision-register-v0-he.md`](../peace-table-decision-register-v0-he.md) — ADR-style register of the ten pre-pilot product decisions listed in architecture §19; version 0.4 keeps the same three explicit operator decisions (`Decided`) and seven `Open` entries (including PTDR-02 and PTDR-09), recording only that the foundation v0.3 constitutional path is now resolved — pilot policy/role/presence details for PTDR-02/PTDR-09 remain unresolved and live behavior is unchanged.
- [`../peace-table-mandate-authority-v0-he.md`](../peace-table-mandate-authority-v0-he.md) — **Proposed** ADR for mandate-based dual-model delegated operational authority, addressing architecture §19 items 2 and 9 (PTDR-02, PTDR-09). Its §14 constitutional question was resolved by Adi's Option 3 selection (Issue #60) and adopted as foundation v0.3 §9.1; the operational mechanism it describes (§3–§13, §15–§18) remains **Proposed**, not approved policy, and live Tier-2 execution stays blocked pending a separate PTDR-02/PTDR-09 `Decided` record and a satisfied Shadow Mode exit criterion.
