# PTDR-04 — מתקן הפיקסצ'רים

PTDR-04 היא `Open`, והרשומה עצמה מבקשת ראיות לפני אימוץ: *"fixtures משלב 0 של
הארכיטקטורה עם התנגדויות מהותיות ידועות מראש"*. זו התיקייה הזאת.

## איך מריצים

```
node peace-table/evidence/ptdr-04/run.js
```

או `npm run ptdr04`. אין מה להתקין ואין תלויות — Node בלבד, בהתאם ל-Axiom 10.

## מה יש כאן

- [`fixtures.js`](fixtures.js) — שמונה תרחישים. לכל אחד מהותיות **שנקבעה מראש**,
  ולכל אחד מקור מששת המקורות שיסוד §8 מונה. `sentiment` הוא מה שהחדר חושב, והוא
  לעולם אינו האמת — הוא קיים כדי שאפשר יהיה לראות מה קורה כשמסווג הולך אחריו.
- [`policies.js`](policies.js) — ארבע מדיניויות מועמדות, ושני מסווגים: אידיאלי,
  ואחד שהולך אחרי החדר. השני אינו איש קש — הוא הכשל שיסוד §2.5 קיים כדי לאסור.
- [`run.js`](run.js) — מריץ כל מדיניות על כל פיקסצ'ר תחת שני התנאים, ומדפיס את
  שתי טעויות הסיווג בנפרד: מחיקת מהותיות מול חסימת העדפה.

הממצאים, ומה שהם אומרים ומה שלא, ב-[`findings-v0-he.md`](findings-v0-he.md).

## מה זה לא

פיקסצ'רים כתובים ביד שמהותיותם נקבעה בידי מי שכתב אותם. המתקן בודק **מכניקה של
מדיניות** — מה כל כלל עושה בהינתן קלט — ולא התנהגות של אנשים. הוא אינו יכול
לומר כמה אנשים יצהירו בכנות על מקור ההתנגדות שלהם, וזה בדיוק המספר שקובע אם
מדיניות D עובדת. ריצה הגונה עם אנשים אמיתיים היא ראיה אחרת, ואינה כאן.
