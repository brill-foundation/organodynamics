# PTDR-04 — מתקן הפיקסצ'רים

PTDR-04 היא `Open`, והרשומה עצמה מבקשת ראיות לפני אימוץ: *"fixtures משלב 0 של
הארכיטקטורה עם התנגדויות מהותיות ידועות מראש"*. זו התיקייה הזאת.

## איך מריצים

```
node peace-table/evidence/ptdr-04/run.js
```

או `npm run ptdr04`. אין מה להתקין ואין תלויות — Node בלבד, בהתאם ל-Axiom 10.

## מה יש כאן

- [`fixtures.js`](fixtures.js) — תשעה תרחישים. לכל אחד מהותיות **שנקבעה מראש**
  ומקור מששת המקורות שיסוד §8 מונה, **והיקף תחולה מוצהר**: על אילו קבוצות
  ההכרעה חלה, מי מהן דיבר, על מה היא נשענת, ומה מזה מגובה. `sentiment` הוא מה
  שהחדר חושב, והוא לעולם אינו האמת — הוא קיים כדי שאפשר יהיה לראות מה קורה
  כשמסווג הולך אחריו.
- [`coverage.js`](coverage.js) — מודל ה-coverage, מורכב מחמישה מקומות בקורפוס
  ולא מומצא כאן; הקובץ מצטט את חמשתם. הוא **אינו מחזיר סקלר**: אפשר לשאול אותו
  אילו קבוצות לא נשמעו ואילו תלויות אינן מגובות, ואי אפשר לקבל ממנו מספר לחתוך
  בו. כך "coverage ולא רק count" נאכף בממשק.
- [`policies.js`](policies.js) — חמש מדיניויות מועמדות, ומסווגים וסוקרים בשני
  מצבים: אידיאלי, ואחד שהולך אחרי החדר או פשוט אינו שם. השני אינו איש קש — הוא
  הכשל שיסוד §2.5 קיים כדי לאסור.
- [`run.js`](run.js) — מריץ כל מדיניות על כל פיקסצ'ר תחת שלושה תנאים, ומדפיס את
  שתי טעויות הסיווג בנפרד — מחיקת מהותיות מול חסימת העדפה — ומודד את החובה
  להחזיר «אין בסיס להכרעה» במקום להצהיר עליה.

הממצאים, ומה שהם אומרים ומה שלא, ב-[`findings-v0-he.md`](findings-v0-he.md).

## מה זה לא

פיקסצ'רים כתובים ביד שמהותיותם **והיקף התחולה שלהם** נקבעו בידי מי שכתב אותם.
המתקן בודק **מכניקה של מדיניות** — מה כל כלל עושה בהינתן קלט — ולא התנהגות של
אנשים. הוא אינו יכול לומר כמה אנשים יצהירו בכנות על מקור ההתנגדות שלהם, וזה
בדיוק המספר שקובע אם D ו-E עובדות. וההיקף הוא בדיוק המקום שבו אדם אמיתי יטעה
או יטה: מי נספר כ«קבוצה שההכרעה חלה עליה» היא שאלה שאיש לא הכריע. ריצה הגונה
עם אנשים אמיתיים היא ראיה אחרת, ואינה כאן.
