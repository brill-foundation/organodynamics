# PTDR-04 — מתקן הפיקסצ'רים

PTDR-04 היא `Open`, והרשומה עצמה מבקשת ראיות לפני אימוץ: *"fixtures משלב 0 של
הארכיטקטורה עם התנגדויות מהותיות ידועות מראש"*. זו התיקייה הזאת.

## איך מריצים

```
node peace-table/evidence/ptdr-04/run.js
```

או `npm run ptdr04`. אין מה להתקין ואין תלויות — Node בלבד, בהתאם ל-Axiom 10.

## מה יש כאן

- [`fixtures.js`](fixtures.js) — אחד-עשר תרחישים, וכל ששת המקורות של §8 מיוצגים. לכל אחד מהותיות **שנקבעה מראש**
  ומקור מששת המקורות שיסוד §8 מונה, **והיקף תחולה מוצהר**: על אילו קבוצות
  ההכרעה חלה, מי מהן דיבר, על מה היא נשענת, ומה מזה מגובה. `sentiment` הוא מה
  שהחדר חושב, והוא לעולם אינו האמת — הוא קיים כדי שאפשר יהיה לראות מה קורה
  כשמסווג הולך אחריו.
- [`coverage.js`](coverage.js) — מודל ה-coverage. **הצורה** מורכבת מחמישה מקומות
  בקורפוס והקובץ מצטט את חמשתם; **הספים מוצעים ולא נגזרים**, ומסומנים ככאלה,
  ושתי מערכות סף מורצות כדי להראות כמה המסקנות תלויות בבחירה שאיש לא הכריע. הוא
  **אינו מחזיר סקלר**: אפשר לשאול אותו אילו קבוצות לא נשמעו ואילו תלויות אינן
  מגובות, ואי אפשר לקבל ממנו מספר לחתוך בו. כך "coverage ולא רק count" נאכף בממשק.
- [`policies.js`](policies.js) — ארבע מדיניויות מהותיות, ועליהן `withCoverage`
  שעוטפת כל אחת מהן. coverage אינו מדיניות חמישית: §8 מונה אותו לצד מהותיות ולא
  במקומה, ולכן הוא ציר נפרד ומורץ ככזה. בנוסף מסווגים, מצהירים וסוקרים במצב
  אידיאלי ובמצבי כשל. אלה אינם אנשי קש — הם הכשל שיסוד §2.5 קיים כדי לאסור.
- [`run.js`](run.js) — מריץ כל מדיניות, עם העטיפה ובלעדיה, תחת שתי מערכות סף
  וארבעה תנאים; מדפיס את שתי טעויות הסיווג בנפרד — מחיקת מהותיות מול חסימת
  העדפה — ומודד את החובה להחזיר «אין בסיס להכרעה» במקום להצהיר עליה.

הממצאים, ומה שהם אומרים ומה שלא, ב-[`findings-v0-he.md`](findings-v0-he.md).

## מה זה לא

פיקסצ'רים כתובים ביד שמהותיותם **והיקף התחולה שלהם** נקבעו בידי מי שכתב אותם.
המתקן בודק **מכניקה של מדיניות** — מה כל כלל עושה בהינתן קלט — ולא התנהגות של
אנשים. הוא אינו יכול לומר כמה אנשים יצהירו בכנות על מקור ההתנגדות שלהם, וזה
בדיוק המספר שקובע אם D ו-E עובדות. וההיקף הוא בדיוק המקום שבו אדם אמיתי יטעה
או יטה: מי נספר כ«קבוצה שההכרעה חלה עליה» היא שאלה שאיש לא הכריע. ריצה הגונה
עם אנשים אמיתיים היא ראיה אחרת, ואינה כאן.
