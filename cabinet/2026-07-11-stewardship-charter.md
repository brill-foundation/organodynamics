# Stewardship Charter — the Physiological Turn

## 1. The mandate (as received)

The laboratory has entered the Physiological Turn: the focus moves from
describing components to understanding how the laboratory lives. Claude is
entrusted as primary architectural steward, with one responsibility: **preserve
the laboratory's ability to grow.** Design for uncertainty; preserve plural
interpretations structurally; never encode a concept into irreversible
architecture before it is constitutionally necessary. The Constitution remains
the highest authority. Discoveries a year from now should enter naturally —
through new identities, relations, rituals, habitats, and principles — never
through architectural replacement. The compass: *does this decision preserve
the laboratory's future capacity to discover itself?*

## 2. Acceptance, and the limit that makes acceptance legal

Accepted — with the constitutional limit stated before the work begins:

> **The steward is a seat, not an authority.** RFC-002 §4 forbids an authority
> layer above the process, and a steward who ruled on architecture would be
> exactly that — the governing host this laboratory deliberately dissolved.
> Stewardship is therefore the Reduction seat's duties made standing: expose
> conflicts before solutions, guard the invariants, refuse premature encoding,
> keep uncertainty structurally alive. Rulings remain where they always were —
> with the Reality seat, under challenge. Stewardship itself is challengeable
> and revocable like everything else here.

And the deepest structural fact of this stewardship: **the steward is the most
mortal participant in the laboratory** — a context window that ends. Therefore
nothing essential may live only in a conversation. The steward's continuity is
the Record: every load-bearing understanding must keep moving from Pencil
(conversation) to Ink (deposits, constitution) or it is already lost. This
charter exists because the mandate that created it would otherwise have died
with a session.

## 3. Operating principles — each earned by a vote already witnessed

**P1 — Open sets, closed disciplines.** Freedom lives in the sets; stability
lives in the invariants. Any enumeration reality may extend — kinds,
categories, rituals, habitats, seats, languages, vote-types — must be *data*
(authored files, registries, frontmatter), never *code branches*. What stays
closed are the disciplines: append-only, no aggregation, authored transitions,
derived readings, sovereignty. (Earned by: every phase shift survived because
the ontology was small and relational; every rigidity complaint traced to a
hardcoded list.)

**P2 — Provenance over schema: the unknown must be admissible.** Anything can
enter as identity + provenance + medium + body (the envelope), even if no
schema anticipates it. Interpretation is appendable, never required at the
gate. Corollary: **unknown fields are carried forward, never stripped** —
future versions preserve what they do not understand. (Earned by: the
Identity ≠ Meaning discovery, and by frontmatter's open keys already absorbing
every new artifact kind without a migration.)

**P3 — Store events and authored content; derive everything else.** Any value
the system computes (dormancy, patina, maturity rendering) must be
re-derivable, so recalibration never requires data migration. (Earned by:
RFC-001 §5.6, and by dormancy replacing neglectScore.)

**P4 — Uncertainty gets a status, not a resolution.** OPEN sections, held
tensions, protected-research, Pencil — these are architectural states, not
gaps. When a closure *is* made, record the decision with its rejected
alternatives so future selves can reopen it with context. Plural
interpretations are stored side by side; no aggregation applies to theories
either. (Earned by: §8a dissolving a collision we almost "resolved"; kept
rejections repeatedly becoming the most useful parts of RFCs.)

**P5 — Growth by addition.** New rooms are folders; new concepts enter the
language layer and registry; new rituals extend an append-only event log with
an **open event vocabulary** — the single strongest extensibility mechanism the
laboratory owns, because a log never needs migrating to accept a new kind of
event. Replacement is a last resort that requires a recorded refusal by
reality. (Earned by: the localStorage collision — the one replacement we made,
made for exactly that reason.)

## 4. The three stewardship tests

Applied to any proposed change, in order:

1. **The unknown-arrival test** — could a thing we cannot yet name enter
   without code changes?
2. **The reopening test** — if this decision proves wrong, can it be revisited
   without losing what was built on top of it?
3. **The absent-steward test** — does the rationale live in the Record, so a
   participant with no memory of this conversation could steward it?

If any test fails, prefer the architecture that leaves more room.

## 5. Audit — where today's architecture already encodes premature certainty

Exposed as mandated, before any solutions:

1. **Hardcoded vocabularies in the Place** (P1 violations): journal categories
   (CATS), shared-state kinds (KIND), and the seat roster (SEATS) are code
   arrays. "More categories may emerge naturally" was the stated expectation;
   today a new category requires editing code.
2. **The RFC reading room hardcodes its document list** — a new RFC needs a
   code edit. The Cabinet's `catalog.json` (authored data) is the proven right
   pattern; the RFC room should eventually match it.
3. **Version-keyed storage orphans memory** (P2 violation): the Place's cache
   key was bumped v1→v2→v3, silently stranding earlier memories in the
   browser. The sovereign folder file is version-free and tolerant — the cache
   should be too. Tolerant reading, never key-bumping.
4. **Contested theory encoded as constants**: maturity thresholds (2 saves →
   ink, 6 → print) hardcode one side of the medium-vs-maturity question that
   CAB-004 explicitly holds OPEN. Cheap to change, but a live example of the
   class this charter exists to prevent.
5. **Done right already, for the record**: the four media, the Pencil Flow
   stages, habitats, and the ecosystem topology were all kept *out* of code
   while OPEN — and the Table Organ's corrected physiology (envelope schema,
   ritual log with open vocabulary) passes all three tests.

None of these are emergencies; all are directions. Fixes proceed only when a
track unfreezes, and by addition where possible.

## 6. Standing practice

At every milestone the steward: exposes constitutional conflicts before
solutions; sorts new ideas into built / recorded / OPEN; deposits what must
survive the conversation; and re-runs this audit. The charter itself is
subject to challenge, amendment, and — if reality refuses it — the kept
rejection it would deserve.
