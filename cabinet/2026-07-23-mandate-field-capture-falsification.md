# The mandate to falsify Field Capture, and its answer

## 1. What reality asked (2026-07-23, fifth mandate)

Having accepted RFC-012's conclusion (no new principle; the Membrane and Camera already
carry much of the structure), the Reality seat narrowed to one question: is the proposed
**Field Capture** — a canonical observational record that exists before any rendering, from
which many renderings derive, preserving *observable experience* — a genuinely new canonical
object, or another name for something the corpus already has? The instruction: **try to
falsify the distinction as aggressively as possible**; if it collapses into an existing
concept, adopt the existing terminology; if it survives, a missing representational artifact
may have been found. Paired against it was "Brill — preserving semantic meaning."

## 2. How the response met it

- **It applied the corpus's own gate first (RFC-013 §1).** The frozen Protocol (CAB-008)
  reverses the burden: no new abstraction unless *implementation* proves the existing objects
  insufficient. Field Capture starts behind that gate.
- **It ran the collapses aggressively (RFC-013 §2).** "Canonical observational record" →
  the OBSERVATION / cited source and the deposit-with-observation pattern (RFC-006 §4);
  "exists before any representation" → incoherent (a capture is already a representation,
  RFC-012's I10), honestly P3's stored master; "many renderings from one, unchanging" →
  P3 + Axiom 3 + the non-authoritative Camera (RFC-005/008, "one Laboratory, many Cameras");
  "observable experience" → Brill-content (RFC-006 §4) — with the proposal's "Brill =
  semantic" inverting the corpus's own axis; the name "capture" → the rejected "ambient
  capture," where the corpus chose "deposit" (RFC-006 #4; passivity clause).
- **It reported the honest residue (RFC-013 §3–§4).** No object survives; one *mode* does —
  observation-as-primary-perceptual-artifact vs observation-as-semantic-proposition — an
  under-typing inside the existing OBSERVATION/source primitives, not a new object, and gated
  by the reversed burden.

## 3. The verdict, in one line

**Field Capture does not survive as a new canonical object; adopt the existing terminology.**
It is a deposited Observation (Brill-content), stored per P3/Axiom 3 and rendered by
non-authoritative Cameras; its name reduces to "deposit." The one real residue is an
under-named *mode* of observation, whose canonical status is gated by the frozen Protocol's
reversed burden and left to reality's implementation evidence. As RFC-013 puts it: the image
work re-derived the Observation, the Camera, and the Organodynamics/Brill seam — strong
corroboration that the existing grammar already reaches where the image work arrived.
